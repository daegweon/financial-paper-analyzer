# PaperSignal — Inline Evidence Popover UX

> **작성:** 2026-11-21 KST  
> **구현:** PR #39 — 인라인 원문 근거 정보 팝오버  
> **목표:** 근거를 접어두는 별도 행조차 분석 화면에 남지 않도록 하고, 사용자가 관심을 보일 때만 원문 인용을 노출한다.

## 1. 기존 접이식 UI의 문제

PR #38의 `details/summary`는 인용문을 숨겼지만 각 근거마다 전체 폭의 접기 행과 페이지 배지가 남았다. 근거가 여러 개면 사용자가 내용을 읽기 전에 이미 수많은 UI 행을 훑어야 했다. 숨김은 달성했지만 화면 밀도와 시각적 우선순위를 개선하지 못했다.

## 2. 새 인터랙션

- 본문과 주장 옆에 17px 원형 `i` 아이콘만 배치한다.
- 마우스 포인터가 아이콘에 들어오면 인용문 미리보기를 표시한다.
- 팝오버 자체로 포인터를 이동해도 사라지지 않는다.
- 아이콘을 클릭하면 포인터가 이동해도 팝오버를 고정한다.
- 바깥을 클릭하거나 Escape를 누르면 닫힌다.
- 키보드 포커스도 hover와 동일하게 팝오버를 열며, 팝오버 안의 닫기 버튼과 PDF 페이지 링크를 사용할 수 있다.
- 터치 환경에서는 아이콘을 탭해 열고 닫기 버튼 또는 바깥 영역을 탭해 닫는다.
- 하나의 `EvidenceList`에 근거가 여러 개면 **하나의 i 아이콘**으로 묶고, 팝오버 내부에서 페이지별 인용문을 스크롤해 확인한다.
- 원본 PDF가 연결된 경우에만 해당 페이지 이동 링크를 표시한다.

## 3. 정보 구조 및 시각적 위계

- 본문은 항상 보이고 근거 UI는 인라인 아이콘 하나만 남긴다.
- 페이지 번호와 인용문은 기본 화면에서 숨기고 팝오버 안에만 표시한다.
- 기존 초록색 전체 폭 근거 행과 카드 테두리를 제거한다.
- 실증 결과와 주니어 3분 가이드도 동일한 팝오버 컴포넌트를 사용한다.
- 표·그래프 학습 카드는 원래의 학습 카드 펼치기 구조를 유지하되, 펼친 카드 안의 원문 인용을 별도 팝오버로 바꾼다. PDF 페이지 이동 버튼의 중복 노출은 제거한다.

## 4. 접근성 검토

설계는 W3C WCAG 2.2 성공 기준 1.4.13(Content on Hover or Focus)의 세 조건을 반영한다.

- **Dismissible:** Escape와 닫기 버튼, 바깥 클릭으로 닫을 수 있다.
- **Hoverable:** 트리거에서 팝오버로 포인터를 이동해도 열려 있다.
- **Persistent:** 클릭으로 고정하면 포인터가 떠나도 유지되고, 사용자가 닫거나 바깥을 클릭할 때까지 읽을 수 있다.
- 키보드 포커스도 같은 내용을 노출하며, 모바일 터치에는 hover에 의존하지 않는 클릭 동작을 제공한다.

참고: https://www.w3.org/WAI/WCAG22/Understanding/content-on-hover-or-focus

이 작업은 W3C 지침에 근거한 내부 설계 검토이며, 외부 인간 접근성 감사나 공식 WCAG 적합성 인증을 의미하지 않는다.

## 5. 인쇄 및 PDF 내보내기

화면에서 팝오버가 닫혀 있어도 인쇄 미디어에서는 모든 원문 인용문을 정적 본문으로 펼쳐 출력한다. 아이콘과 닫기 버튼은 인쇄에서 숨긴다. 화면의 간결함이 보고서의 출처 정보를 누락시키지 않게 한다.

## 6. 변경 파일

- `frontend/components/EvidencePopover.tsx` / `.module.css`: 공통 hover/focus/click/touch 팝오버.
- `frontend/app/page.tsx`: 모든 `EvidenceList`를 인라인 팝오버로 변경하고 주장 텍스트 옆에 배치.
- `frontend/components/JuniorPaperGuide.tsx`: 직접 인용을 공통 팝오버로 전환.
- `frontend/components/JuniorVisualReading.tsx`: 표·그래프 인용과 유의성 주석을 하나의 팝오버로 묶고 중복 페이지 버튼 제거.
- 관련 CSS: 전체 폭 접기 행과 불필요한 인용 블록 스타일 제거, 인쇄 규칙 변경.
- `frontend/tests/e2e/auth-and-workspace.spec.ts`: hover, 팝오버로 포인터 이동, 키보드 포커스, 클릭 고정, Escape, 바깥 클릭, 모바일 탭, 인쇄, 주니어 가이드 회귀 테스트.
