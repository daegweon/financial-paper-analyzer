## 사용자 요청

1. 논문 분석 보고서에서 초록색 원문 인용 박스가 모두 펼쳐져 있어 긴 페이지를 읽기 어렵다. 원문 근거에 관심 있는 사용자만 인용문과 PDF 이동 링크를 열 수 있게 한다.
2. 로그인 직후 메인 화면에서 공개 금융 논문 탐색보다 사용자가 이미 보유한 논문과 분석 이력을 먼저 보여준다. 새 논문을 추가로 찾거나 가져오려면 아래로 스크롤하도록 순서를 변경한다.

## 1. 원문 근거 상세 표시

### 동작 — PR #39의 인라인 팝오버로 개선

- PR #38의 반복되는 접기 행은 더 이상 최종 UX로 사용하지 않는다.
- 근거가 연결된 주장 옆에 작은 인라인 `i` 아이콘 하나만 표시한다.
- 주장/설명 텍스트 자체에 마우스를 올리면 포인터 근처에서 원문 인용 팝오버가 열리고, 텍스트 또는 아이콘 위에서 포인터를 움직이면 따라온다. 팝오버 안으로 들어가면 위치를 고정해 인용문을 읽고 PDF 페이지 링크를 클릭할 수 있다.
- 아이콘 클릭은 팝오버를 고정하며 바깥 클릭/ESC로 닫는다. 터치와 키보드 조작도 지원한다.
- 한 주장에 연결된 여러 페이지 인용은 여러 행/아이콘으로 분리하지 않고 단일 팝오버 안에 묶는다.
- 인쇄/PDF 출력에는 모든 원문 근거를 계속 포함하고 화면 전용 i 아이콘은 숨긴다.
- 공통 `EvidencePopover`는 분석 보고서의 `EvidenceList`와 주니어 3분 읽기 가이드에서 재사용한다.

## 2. 로그인 후 메인 화면 순서

기존:
1. 시작 안내
2. 나의 연구 라이브러리 제목
3. 공개 금융 논문 찾아보기
4. 논문 통계와 내 라이브러리

변경:
1. 나의 연구 라이브러리 제목과 파일 직접 추가 버튼
2. 내 작업 공간: 전체/완료 분석 통계, 논문 목록, 분석 작업 탭, 검색·필터·정렬·비교, 오류 및 상태
3. PaperSignal 시작 안내(접을 수 있는 베타 가이드)
4. 공개 금융 논문 찾아보기: PDF URL 가져오기, OpenAlex 검색, 추천 논문, 인용 수 및 정렬

기존 PDF 직접 업로드 버튼은 제목 옆에서 계속 사용할 수 있다. 공개 PDF URL과 추천/검색 목록을 통한 가져오기는 아래 탐색 영역에서 이용한다. 공개 논문 API, 데이터, 인증 및 개인 라이브러리 저장 흐름은 변경하지 않는다.
