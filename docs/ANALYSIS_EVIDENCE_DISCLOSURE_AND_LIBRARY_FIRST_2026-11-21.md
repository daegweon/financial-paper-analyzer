# PaperSignal — 원문 근거 접기 및 내 작업 공간 우선 배치

> **작성:** 2026-11-21 KST  
> **구현 PR:** #38 — 근거 상세 표시와 라이브러리 우선 랜딩 화면  
> **상태:** 개발 브랜치 / CI 검증 및 Production 반영 대기

## 사용자 요청

1. 논문 분석 보고서에서 초록색 원문 인용 박스가 모두 펼쳐져 있어 긴 페이지를 읽기 어렵다. 원문 근거에 관심 있는 사용자만 인용문과 PDF 이동 링크를 열 수 있게 한다.
2. 로그인 직후 메인 화면에서 공개 금융 논문 탐색보다 사용자가 이미 보유한 논문과 분석 이력을 먼저 보여준다. 새 논문을 추가로 찾거나 가져오려면 아래로 스크롤하도록 순서를 변경한다.

## 1. 원문 근거 상세 표시

### 동작

- `EvidenceList`의 각 원문 근거를 기본 닫힘 상태의 HTML `details/summary`로 표시한다.
- 접힌 상태에는 **원문 근거 보기 · p.N · 인용문 확인**만 표시하고 원문 인용 텍스트는 숨긴다.
- 사용자가 해당 항목을 열면 원문 인용 전문과 원문 PDF 페이지 이동 버튼/링크를 함께 표시한다.
- 다시 누르면 접힌 상태로 돌아간다.
- 이 변경은 서지정보, 연구 질문, 방법론, 표본 수 대조, 실증 결과, 유의성 주석, 강건성, 한계, 시사점, 검증된 원문 근거 등 `EvidenceList`를 사용하는 모든 보고서 위치에 적용된다.
- 주니어 3분 읽기 가이드의 실증 결과 직접 인용도 같은 공통 disclosure 스타일로 변경한다.
- 표·그래프 학습 카드는 기존부터 카드 자체가 접히는 구조이므로 유지한다. 카드가 열린 경우 인용 근거를 확인할 수 있다.

### 접근성 및 내보내기

- 브라우저 기본 `details/summary` 동작을 사용해 마우스뿐 아니라 키보드로도 열고 닫을 수 있다.
- 요약 행에 페이지 번호를 유지해 인용문을 열기 전에도 근거 위치를 알 수 있다.
- **보고서 인쇄/PDF 내보내기에서는 화면에서 접혀 있던 근거도 모두 펼쳐서 출력**하고, 접기 요약 행은 인쇄하지 않는다. 화면의 간결함 때문에 저장된 보고서의 근거가 누락되지 않게 한다.

## 2. 로그인 후 메인 화면 순서

기존:
1. 시작 안내
2. 나의 연구 라이브러리 제목
3. 공개 금융 논문 찾아보기
4. 논문 통계와 내 라이브러리

변경:
1. 나의 연구 라이브러리 제목과 파일 직접 추가 버튼
2. 내 작업 공간: 전체/완료 분석 통계, 논문 목록, 분석 작업 탭, 검색·필터·정렬·비교, 오류 및 상태
3. PaperSignal 시작 안내(접을 수 있는 베타 가이드)
4. 공개 금융 논문 찾아보기: PDF URL 가져오기, OpenAlex 검색, 추천 논문, 인용 수 및 정렬

기존 PDF 직접 업로드 버튼은 제목 옆에서 계속 사용할 수 있다. 공개 PDF URL과 추천/검색 목록을 통한 가져오기는 아래 탐색 영역에서 이용한다. 공개 논문 API, 데이터, 인증 및 개인 라이브러리 저장 흐름은 변경하지 않는다.

## 5. 검증 및 배포 상태

PR #38의 CI가 완료되면 이 문서의 상태와 실제 통과한 테스트 수를 갱신한다. CI는 다음을 검증한다.

- 기존 프런트엔드 단위 테스트 및 TypeScript/Next 프로덕션 빌드.
- 기존 분석 화면·로그아웃·PDF·원문 근거 이동 E2E.
- 원문 인용 기본 접힘 및 사용자가 선택해 펼치는 동작.
- 라이브러리 우선, 공개 논문 탐색 후순위 DOM 순서.
- 모바일/태블릿/데스크톱 반응형 화면.

PR #38 Preview에서 확인한 후 병합/Production 배포를 진행한다. 병합 전에는 공식 운영 화면에 반영됐다고 간주하지 않는다.
