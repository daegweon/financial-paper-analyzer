# 주니어 금융논문 방법론 학습 카드

`methodology_catalog.json`은 계량경제학·금융실증에서 자주 등장하는 방법론을 한국어로 설명하는 일반 교육 콘텐츠입니다. 특정 논문이 해당 방법론을 실제로 사용했거나 특정 결과를 냈다는 증거가 아닙니다.

현재 포함된 주제: OLS, 패널 고정효과, 패널 확률효과, DiD, IV/2SLS, 이벤트 스터디, 자산가격 요인모형, GARCH, PCA.

각 카드에는 핵심 개념, 대표 수식, 논문 표 읽는 순서, 해석상 주의점, 이해도 확인 질문과 해설이 포함됩니다.

카드 생성:

```bash
python learning/build_methodology_cards.py --out learning/methodology-cards.md
```

논문 분석 결과와 결합할 때는 반드시 해당 논문의 원문 근거와 분리해 표시해야 합니다. 일반 개념 설명을 논문별 추출 사실이나 인용 근거로 취급하지 마세요.
